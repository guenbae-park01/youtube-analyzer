# YouTube 검색 및 분석 도구 📺

Python Flask와 HTML/CSS/JavaScript를 사용한 YouTube 영상 검색 및 분석 웹 애플리케이션입니다.

## 주요 기능 ✨

### 1. YouTube API 연동
- Google YouTube Data API v3 키 입력 및 검증
- API 연결 상태 실시간 확인

### 2. 고급 검색 기능
- **키워드 검색**: 원하는 키워드로 영상 검색
- **검색 기간 필터**: 전체 / 최근 7일 / 최근 30일 / 사용자 지정
- **영상 길이 필터**: 전체 / 숏폼(3분 이하) / 롱폼(3분 이상)
- **최소 조회수 설정**: 특정 조회수 이상의 영상만 검색
- **최소 구독자 수 설정**: 특정 구독자 수 이상의 채널만 검색
- **검색 결과 수 조절**: 10개 / 20개 / 50개

### 3. 검색 결과 표시
- **카드형 뷰**: 썸네일 중심의 그리드 레이아웃
- **리스트형 뷰**: 상세 정보가 포함된 리스트 레이아웃
- 실시간 조회수, 좋아요, 댓글 수 표시
- 채널 정보 및 구독자 수 표시

### 4. 성과 지표
- **떡상지표**: 조회수 대비 참여율(좋아요+댓글) 계산
- **성과지표**: 구독자 수 대비 조회수 비율 계산

### 5. 영상 대본(자막) 추출
- YouTube 자막 API를 통한 자동 대본 추출
- 한국어 우선, 영어 자막 지원
- 대본 복사 기능
- 팝업 창으로 깔끔한 표시

### 6. 댓글 분석
- 영상의 댓글 최대 100개 추출
- 작성자, 댓글 내용, 좋아요 수, 작성일 표시
- CSV 파일로 다운로드 가능

### 7. AI 벤치마킹 분석
- 유튜브 영상 성공 요인 분석 프롬프트 제공
- 썸네일 & 오프닝 일치성 분석
- 감정의 방향성 & 논리 구조 분석
- 이탈 방지 장치 분석
- 시청자 집착 구간 분석
- Gemini AI 직접 연결 버튼

## 설치 방법 🚀

### 1. Python 설치
Python 3.8 이상이 설치되어 있어야 합니다.

### 2. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

또는 개별 설치:
```bash
pip install Flask flask-cors youtube-transcript-api requests
```

### 3. YouTube API 키 발급
1. [Google Cloud Console](https://console.cloud.google.com/) 접속
2. 새 프로젝트 생성
3. "API 및 서비스" > "라이브러리" 메뉴로 이동
4. "YouTube Data API v3" 검색 및 활성화
5. "사용자 인증 정보" > "사용자 인증 정보 만들기" > "API 키" 선택
6. 생성된 API 키 복사

## 사용 방법 📖

### 1단계: API 키 입력
- 왼쪽 패널의 "API 설정" 섹션에 YouTube API 키 입력
- "API 연결 확인" 버튼을 클릭하여 키 유효성 검증

### 2단계: 검색 조건 설정
- 키워드 입력
- 검색 기간 선택
- 영상 길이 필터 선택
- 최소 조회수 입력 (선택)
- 최소 구독자 수 입력 (선택)
- 검색 결과 수 선택

### 3단계: 검색 실행
- "검색 시작" 버튼 클릭
- 오른쪽 패널에 검색 결과 표시

### 4단계: 결과 분석
- **카드형/리스트형 뷰 전환**: 상단 버튼으로 보기 방식 변경
- **▶️ 보기**: YouTube에서 영상 시청
- **📝 대본**: 영상 자막/대본 추출 및 복사
- **💬 댓글**: 댓글 목록 확인 및 CSV 다운로드
- **🤖 AI분석**: 벤치마킹 분석 프롬프트 생성 및 Gemini AI 연결

## 기술 스택 💻

### 백엔드
- **Flask**: Python 웹 프레임워크
- **Flask-CORS**: CORS 처리
- **youtube-transcript-api**: YouTube 자막 추출
- **requests**: HTTP 요청 처리

### 프론트엔드
- **HTML5**: 마크업
- **CSS3**: 스타일링 (그라디언트, 애니메이션)
- **JavaScript**: 동적 기능 구현
- **Fetch API**: 비동기 통신

### API
- **YouTube Data API v3**: 영상 검색 및 정보 조회
- **YouTube Transcript API**: 자막 추출

## 주의사항 ⚠️

1. **API 할당량**: YouTube Data API는 하루 할당량이 제한되어 있습니다.
2. **자막 없는 영상**: 자막이 없거나 비활성화된 영상은 대본 추출이 불가능합니다.
3. **댓글 비활성화**: 댓글이 비활성화된 영상은 댓글 추출이 불가능합니다.
4. **네트워크 연결**: 인터넷 연결이 필요합니다.

## 문제 해결 🔧

### API 키 오류
- API 키가 올바른지 확인
- YouTube Data API v3가 활성화되어 있는지 확인
- 할당량이 남아있는지 확인

### 자막 추출 실패
- 영상에 자막이 있는지 확인
- 다른 영상으로 테스트

### 댓글 추출 실패
- 영상에 댓글이 활성화되어 있는지 확인
- API 할당량 확인
