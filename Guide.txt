# YouTube 검색 및 분석 도구 사용 가이드 📚

## 빠른 시작 🚀

### 1. 프로그램 실행
```bash
python youtube_analyzer.py
```

### 2. 브라우저에서 열기
주소창에 입력: `http://localhost:5000`

### 3. API 키 설정 (최초 1회)
- Google Cloud Console에서 YouTube Data API v3 키 발급
- 왼쪽 패널의 "API 설정" 섹션에 키 입력
- "API 연결 확인" 버튼 클릭

## 상세 기능 설명 📝

### 1. API 키 발급 방법

#### Step 1: Google Cloud Console 접속
1. https://console.cloud.google.com 접속
2. Google 계정으로 로그인

#### Step 2: 프로젝트 생성
1. 상단의 프로젝트 선택 드롭다운 클릭
2. "새 프로젝트" 클릭
3. 프로젝트 이름 입력 (예: YouTube Analyzer)
4. "만들기" 클릭

#### Step 3: YouTube Data API v3 활성화
1. 왼쪽 메뉴에서 "API 및 서비스" > "라이브러리" 클릭
2. 검색창에 "YouTube Data API v3" 입력
3. "YouTube Data API v3" 클릭
4. "사용 설정" 버튼 클릭

#### Step 4: API 키 생성
1. "API 및 서비스" > "사용자 인증 정보" 클릭
2. "사용자 인증 정보 만들기" 클릭
3. "API 키" 선택
4. 생성된 API 키 복사
5. (선택) 키 제한 설정 권장

### 2. 검색 기능 사용법

#### 기본 검색
```
1. 키워드 입력: "요리 레시피"
2. 검색 시작 버튼 클릭
3. 결과 확인
```

#### 고급 검색 - 검색 기간 설정
- **전체**: 모든 기간의 영상 검색
- **최근 7일**: 일주일 이내 업로드된 영상
- **최근 30일**: 한 달 이내 업로드된 영상
- **사용자 지정**: 원하는 날짜 범위 지정

예시: 최근 7일간 업로드된 "AI 뉴스" 검색
```
키워드: AI 뉴스
검색 기간: 최근 7일
검색 시작 클릭
```

#### 영상 길이 필터
- **전체**: 모든 길이의 영상
- **숏폼 (3분 이하)**: YouTube Shorts 및 짧은 영상
- **롱폼 (3분 이상)**: 긴 형태의 영상

예시: 숏폼만 검색
```
키워드: 운동 루틴
영상 길이: 숏폼 (3분 이하)
```

#### 최소 조회수 필터
인기 있는 영상만 검색하고 싶을 때 사용

예시: 조회수 10만 이상의 영상만 검색
```
키워드: 영어 공부
최소 조회수: 100000
```

#### 최소 구독자 수 필터
특정 규모 이상의 채널만 검색

예시: 구독자 10만 이상의 채널만
```
키워드: 게임 리뷰
최소 구독자 수: 100000
```

### 3. 검색 결과 보기

#### 카드형 뷰
- 썸네일 중심의 그리드 레이아웃
- 한눈에 많은 영상 확인 가능
- 시각적으로 매력적인 표시

#### 리스트형 뷰
- 상세 정보가 포함된 리스트
- 더 많은 데이터 한 번에 확인
- 비교 분석에 유용

#### 전환 방법
상단의 "카드형" 또는 "리스트형" 버튼 클릭

### 4. 성과 지표 이해하기

#### 떡상지표 (Viral Score)
```
계산식: ((좋아요 + 댓글) / 조회수) × 1000
의미: 영상의 바이럴 가능성
높을수록: 시청자 참여도가 높은 영상
```

예시:
- 90% 이상: 매우 높은 참여도, 떡상 가능성 높음
- 50-90%: 높은 참여도
- 10-50%: 보통
- 10% 미만: 낮은 참여도

#### 성과지표 (Performance Score)
```
계산식: (조회수 / 구독자 수) × 100
의미: 채널 파워 대비 영상 성과
높을수록: 구독자를 넘어서는 확산력
```

예시:
- 100% 이상: 구독자보다 훨씬 많은 조회수
- 50-100%: 구독자의 절반 이상이 시청
- 10-50%: 보통
- 10% 미만: 낮은 성과

### 5. 대본 추출 기능

#### 사용 방법
1. 원하는 영상에서 "📝 대본" 버튼 클릭
2. 팝업 창에서 자막 확인
3. "📋 대본 복사" 버튼으로 클립보드에 복사

#### 활용 사례
- 콘텐츠 분석
- 키워드 추출
- 스크립트 연구
- 번역 자료 생성

#### 주의사항
- 자막이 없는 영상은 추출 불가
- 자막이 비활성화된 영상은 추출 불가
- 일부 영상은 자동 생성 자막만 제공

### 6. 댓글 분석 기능

#### 사용 방법
1. 원하는 영상에서 "💬 댓글" 버튼 클릭
2. 팝업 창에서 댓글 목록 확인
3. "💾 댓글 다운로드" 버튼으로 CSV 다운로드

#### CSV 파일 구조
```
작성자, 댓글, 좋아요, 작성일
홍길동, "좋은 영상이네요!", 15, 2024-12-17
김철수, "도움이 되었습니다", 8, 2024-12-16
```

#### 활용 사례
- 시청자 피드백 분석
- 트렌드 키워드 추출
- 감성 분석
- 커뮤니티 반응 파악

### 7. AI 벤치마킹 분석

#### 기능 개요
성공한 YouTube 영상을 분석하여 성공 요인을 파악하는 AI 프롬프트 제공

#### 사용 방법
1. 분석하고 싶은 영상에서 "🤖 AI분석" 버튼 클릭
2. 생성된 분석 프롬프트 확인
3. "📋 프롬프트 복사" 버튼 클릭
4. "🚀 Gemini AI로 분석하기" 버튼 클릭
5. Gemini AI에서 프롬프트 붙여넣기
6. 영상 URL과 썸네일 URL 함께 제공
7. 분석 결과 확인

#### 분석 항목
1. **썸네일 & 오프닝 일치성**: 클릭베이트 vs 진실성
2. **감정의 방향성**: 어떤 본능을 자극하는가
3. **이탈 방지 장치**: 중반부 지루함 극복 전략
4. **시청자 집착 구간**: 가장 반복 시청되는 부분
5. **벤치마킹 적용**: 내 채널에 적용하는 방법

#### 활용 팁
- 같은 카테고리의 인기 영상 분석
- 경쟁 채널 분석
- 트렌드 파악
- 콘텐츠 기획에 활용

## 문제 해결 🔧

### API 할당량 초과
**증상**: "Quota exceeded" 오류 메시지
**원인**: 하루 API 사용량 초과
**해결**:
1. 다음 날까지 대기 (UTC 기준 자정에 리셋)
2. Google Cloud Console에서 할당량 증가 요청
3. 검색 결과 수를 줄여서 검색

### 자막 추출 실패
**증상**: "자막이 없습니다" 메시지
**원인**: 
- 영상에 자막이 없음
- 자막이 비활성화됨
- 비공개 영상
**해결**:
1. 다른 영상으로 시도
2. 자막이 있는 영상인지 YouTube에서 직접 확인

### 댓글 추출 안됨
**증상**: 댓글 목록이 비어있음
**원인**:
- 댓글이 비활성화된 영상
- API 권한 문제
**해결**:
1. 댓글이 활성화된 영상 선택
2. API 키 권한 확인

### 서버 실행 오류
**증상**: "Port already in use" 오류
**원인**: 5000번 포트가 이미 사용 중
**해결**:
```python
# youtube_analyzer.py 마지막 줄 수정
app.run(debug=True, host='0.0.0.0', port=5001)  # 포트 변경
```

## 자주 묻는 질문 ❓

**Q: API 키 없이 사용 가능한가요?**
A: 아니요, YouTube Data API v3 키가 필수입니다.

**Q: 무료로 사용 가능한가요?**
A: 네, Google의 API 무료 할당량 내에서 무료 사용 가능합니다.

**Q: 하루에 몇 번 검색 가능한가요?**
A: API 할당량에 따라 다르지만, 기본 할당량으로 하루 100-200회 정도 가능합니다.

**Q: 모든 영상의 자막을 추출할 수 있나요?**
A: 자막이 있는 영상만 가능합니다. 자막 유무는 YouTube에서 확인하세요.

**Q: 상업적 용도로 사용 가능한가요?**
A: YouTube API 이용 약관을 준수하는 범위 내에서 가능합니다.
